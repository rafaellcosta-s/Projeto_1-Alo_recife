# 📍 Alô, Recife! — Totem Interativo Figital

> **Experenciando o Recife:** Uma nova forma de vivenciar o turismo na cidade através da reestruturação e reaproveitamento da carcaça dos antigos orelhões em totens gamificados interativos.

---

## 📌 Sobre o Projeto

O **Alô, Recife!** é uma solução figital (física + digital) desenvolvida para aproximar turistas e moradores da cultura de Recife. Através de um totem interativo com botões físicos, o usuario responde a um rápido questionário e recebe uma recomendação personalizada de passeio na cidade.

---

## ⚙️ Funcionalidades

- **Questionário Personalizado (6 Perguntas):**
  1. Horário do passeio (Agora mesmo, Manhã, Tarde, Noite).
  2. Região do Recife preferida (Centro Histórico, Zona Norte, Zona Oeste, Zona Sul, etc.).
  3. Tamanho do grupo (Individual, Casal, Família, Grupos).
  4. Tipo de ambiente (Aberto, Fechado, Tanto faz).
  5. Tipo de experiência (História, Arte/Música, Natureza, Gastronomia).
  6. Necessidade de acessibilidade (Sim / Não).
- **Sugestão de Rota:** Exibição detalhada do local recomendado (ex: Paço do Frevo) com horários, valores, acessibilidade e rotas.
- **Navegação Física:** Controlo e seleção de opções através de botões físicos integrados com Arduino.

---

## 🛠️ Tecnologias e Hardware Utilizados

- **Hardware:**
  - Microcontrolador Arduino (ou compatível)
  - Botões físicos (Avançar, Voltar, Selecionar)
  - Display/Ecrã para exibição da interface
- **Software / Linguagens:**
  - C / C++ (Arduino IDE / PlatformIO)
  - HTML / CSS / javascript
